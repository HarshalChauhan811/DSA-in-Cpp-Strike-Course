## 🧠 Detailed Course Syllabus

### 📘 Module 1: C++ Foundations for DSA
- Introduction to C++ & Environment Setup
- Variables, Data Types & I/O
- Operators, Conditions & Loops
- Functions in C++
- Pointers & Dynamic Memory Allocation

---

### 📘 Module 2: Core Concepts of Algorithmic Analysis
- Time & Space Complexity
- Big-O, Big-Ω, Big-Θ Notations
- Best, Average & Worst Case
- Recursion & Call Stack
- Classic Recursion Problems

---

### 📘 Module 3: Basic Data Structures & Algorithms
- Arrays & Dynamic Arrays (Vector)
- Strings (C-style & STL)
- Searching Algorithms
  - Linear Search
  - Binary Search
- Sorting Algorithms
  - Bubble, Selection, Insertion
  - Merge Sort, Quick Sort

---

### 📘 Module 4: C++ Standard Template Library (STL)
- STL Overview
- Containers
  - vector, list, deque
  - stack, queue, priority_queue
  - set, map, unordered_set, unordered_map
- STL Algorithms & Functors

---

### 📘 Module 5: Object-Oriented Programming (OOP)
- Classes & Objects
- Four Pillars of OOP
- Constructors & Destructors
- Designing Data Structures using OOP

---

### 📘 Module 6: Linear Data Structures
- Linked Lists
  - Singly, Doubly, Circular
- Stacks
  - Implementation & Applications
- Queues
  - Circular Queue, Deque
  - BFS Applications

---

### 📘 Module 7: Non-Linear Data Structures
- Trees (Basics & Traversals)
- Binary Search Trees (BST)
- Heaps & Priority Queues
- Hashing & Hash Tables

---

### 📘 Module 8: Advanced Algorithmic Paradigms
- Backtracking
- Divide & Conquer
- Greedy Algorithms
- Dynamic Programming
- Sliding Window Technique

---

### 📘 Module 9: Graphs
- Graph Representations
- BFS & DFS
- Shortest Path Algorithms
- Minimum Spanning Tree
- Topological Sorting
- Strongly Connected Components

---

### 📘 Module 10: Advanced Data Structures & Topics
- Bit Manipulation
- Trie (Prefix Trees)
- AVL Trees
- B-Trees & B+ Trees
- Vector Databases (Conceptual)
